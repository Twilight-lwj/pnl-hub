# 组合收益回测中枢

单文件网页仪表盘：导入同花顺账本流水 → FIFO 成本推算 → 持仓净值日 K 与收益曲线；另含两个手动策略页（施洛斯 / 大肥鱼）、坚果云备份与导入导出。

- 当前版本：**v1.0.3**（2026-11-25）
- 发布形态：**无数据版**——内置账本数据已清空，首次打开为全 0 空态，用页面内「导入同花顺账本流水」或手动录入填入自己的数据
- 仓库形态：**仅源码**——APK / AppImage 等构建产物不入库，克隆后按 [打包说明.md](打包说明.md) 自行构建
- 许可证：[木兰宽松许可证，第 2 版](LICENSE)
- 仓库规范：见 [仓库标准.md](仓库标准.md)

## 快速开始

- **网页版**：浏览器直接打开 HTML，无需联网；数据存在本机 `localStorage`
- **Android**：先构建 APK 再安装（见 [打包说明.md](打包说明.md)），首次打开为空态
- **Linux**：构建出 AppImage 后 `chmod +x` 再运行（默认端口 17812，可用 `--port` / `--browser none` / `--version`）

## 功能

- **同花顺账本页**：导入账本流水（xlsx / csv），按 FIFO + 费用 + 现金分红摊薄推算单位成本，生成持仓净值日 K 与成本基准线；行情走腾讯 `qt.gtimg.cn`
- **手动策略页**：施洛斯A股策略 / 大肥鱼A股策略，逐笔录入，代码与名称可互相查询补全，非交易日流水归到最近交易日
- **指标卡**：总资产、持有市值、货币收益（全手动）、清仓收益、到手分红、持有成本、盈亏比例
- **设置页**：长按标题（或右键）打开，含明暗切换、坚果云备份配置、导出 / 导入数据

## 数据口径

| 页面 | 总资产 | 明细占比 |
|---|---|---|
| 同花顺账本 | 入金合计 + 持有盈亏 + 货币收益 + 清仓收益 | 市值 ÷ 总资产 |
| 手动策略页 | 入金合计 + 浮动盈亏（不含货币收益 / 清仓收益） | 成本市值 ÷ 总资产 |

- 货币收益：完全手动，默认全 0，不读取账本逆回购金额、不自动刷新
- 涨跌配色遵循 A 股习惯：红涨绿跌

完整口径与自检映射见 `组合收益回测中枢_v1.0.3_20261125/策略算法说明.md`。

## 构建

依赖：Python 3 + PyInstaller（Linux 包）、Node.js（跑算法自检）、Android build-tools 与 JDK 17（APK 包）。完整步骤、口令管理与故障排查见 **[打包说明.md](打包说明.md)**。

```bash
cd 组合收益回测中枢_v1.0.3_20261125

# Android APK（模式 B：只换 assets/index.html 与清单字段，dex / arsc 不变）
ANDROID_TOOLS=/path/to/android-tools python3 源码/android/build_apk.py

# Linux AppImage
PY=/path/to/python3 bash 源码/linux/build_appimage.sh

# 口径自检
node 算法自检.js
```

签名口令通过环境变量 `PNLHUB_KS_PASS` 或本地 `密钥/keystore.pass` 提供，不写在代码里。

## 数据与隐私

- 页面内填写的坚果云邮箱 / 应用密码、持仓数据全部保存在本机浏览器，不上传任何服务器
- 仓库内不含真实账本数据（出厂为无数据空态），也不含任何账号凭据

## 安全

- 签名密钥 `*.jks` 与口令文件均被 `.gitignore` 排除，只在构建机本地保存
- 构建 APK 需自备密钥；口令走 `PNLHUB_KS_PASS`。脚本默认校验证书 DN 为 `CN=PnlHub, OU=PnlBoard, O=PnlBoard, C=CN`
- **换签名即换血统**：用不同密钥签出的包与已装机旧包签名不同，系统会拒绝覆盖安装，只能卸载重装（本地 `localStorage` 数据请先导出备份）
- 发现安全问题请通过仓库 Issues 私下告知，不要在公开 Issue 里贴密钥或个人信息

## 已知约束

- `classes.dex` / `resources.arsc` 沿用所复用的通用 WebView 壳（模式 B 只替换页面与清单字段），其中的 `PnlBoardApp`、`Theme.PnlBoard` 属底座既有标识，不代表本项目命名
- AppImage 用同一份源码重建不保证逐字节相同（PyInstaller 打包层非确定性）；判断是否同版本请看内嵌页哈希与 `--version`
